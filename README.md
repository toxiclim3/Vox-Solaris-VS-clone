### Music
At [Audio/Music](Audio/Music), there are empty folders for you to add your own music (since the ones i'm using are copyrighted (licenced?))  
Boss and Normal automatically use what's in the folder  
Extra needs manual assignment in [Utility/music_controller.gd](Utility/music_controller.gd)  

Also: Some assets (Sprites and audio) are not CC0, and therefore should be replaced as soon as possible. Until then, Credits to respective owners  

### On AI usage
Also also: this project used Generative AI, mostly for coding, and also for the title screen parallax assets. I understand what kind of problem GenAI creates, but 1. I am not a programmer, and 2. The professor expected us to use AI for the development, like, we have to use it or we won't make a good enough project within the time frame (or I guess the team would have to be 4 people that actually worked?).   

A bit extra info on point one: I am not studing to be a programmer, but we did have some programming as part of the course, so like 33% of the code comes from the tutorial, 33% from GenAI, and 33% from me. Will try to improve the ratios, but complicated code is going to be too hard for me.  

Before (and if) this game properly releases somewhere, I will replace yoinked and generated assets.
